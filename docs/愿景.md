一）轻量化大模型的本地部署与优化1. 模型选型用 Hugging Face Transformers 对比Llama 3（7B/13B）、Qwen-7B、Mistral-7B等开源模型，从推理速度、内存占用、中文理解精度三个维度评估，选定适配PC端的模型；2. 本地-云端协同机制设定简单规则：单轮短指令（如 “打开记事本”）用本地模型，多轮复杂指令（如 “整理文件夹并写摘要”）调用 Qwen3 API；用 Redis 做高频指令缓存（如 “关闭浏览器”），无需复杂负载均衡算法；离线模式仅保留已缓存指令的执行，不新增复杂逻辑。
（二）MCP协议应用控制框架设计1. 设计标准化接口参考 MCP 协议官方文档（如 Anthropic 发布的MCP协议相关文档），梳理MCP协议的消息格式、数据类型，用 FastAPI 框架设计 RESTful 接口（如/app/start启动应用、/app/close关闭应用）；3. 接口仅覆盖 “应用启停、基础系统设置”2 类核心操作，预留扩展字段支持后续新增功能如菜单导航。开发应用适配插件 筛选 5-8 种最常用 PC 应用（文本编辑器、Chrome/Edge、WPS/office、文件管理器/音量控制）； 用 Python 的 pyautogui、win32gui 库开发插件；插件实现 “打开 / 关闭 / 基础操作”（如浏览器打开网页、记事本新建文件）；用配置文件管理插件，支持手动加载。
（三）蓝牙远程交互模块开发1. 使用开源低延迟传输协议选用 ESP32 的 BLE 开源库， 无需自定义传输协议，语音数据用 OPUS 开源编码库压缩（直接调用 API），结合错误检测机制，仅保证 3 米内传输延迟≤300ms、丢包率 < 3%。协同多设备与管理权限支持 2 台蓝牙设备同时接入；实现设备 MAC 地址白名单；操作日志仅本地文本记录（无需数据库存储）。开发固件基于 ESP32 官方固件模板，实现音频采集与编码传输；主机端用 Python 的 pyserial 库对接 USB 串口；实现 “语音数据上传→指令接收” 的基本功能。
（四）无障碍交互优化1. 优化交互流程简化操作链路，用 Python 的 keyboard 库实现 “一键唤醒”（如按 F12 唤醒语音助手）；基于大模型的上下文理解功能，支持连续指令；紧急响应机制提供语音指令触发（如 “帮帮我” 打开系统设置），暂不开发蓝牙硬件按键。设计多模态反馈语音反馈直接调用千问 TTS 开源工具；反馈逻辑为 “操作成功/失败→语音提示成功/失败”。
（五）系统集成与性能评估1. 集成模块与优化通信设计基于Socket.IO的模块间通信机制，确保语音识别、大模型推理、MCP控制、蓝牙传输的数据流打通；使用Vite打包桌面应用，支持Windows/macOS双系统。性能测试用 Python 的 time 模块统计响应延迟，psutil 统计内存 / CPU 占用；输出简单测试报告（表格形式记录关键指标）。用户体验优化邀请3~5名普通用户与1~2名视障用户参与测试，收集操作效率、易用性评分，迭代优化交互逻辑与语音反馈话术。
