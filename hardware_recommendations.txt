=====================================
语音助手蓝牙/WiFi 硬件模块推荐清单
=====================================

推荐方案：ESP32-S3 + INMP441 + MAX98357A（WiFi WebSocket 通信）
总预算：30-50 元（散件 DIY）/ 85-95 元（一体材料包）

通信方式说明：
- 推荐使用 WiFi WebSocket（同局域网）而非蓝牙音频协议
- 原因：BLE 带宽不够传实时语音；经典蓝牙 HFP/A2DP 编程复杂度极高
- ESP32 连接家里/办公室 WiFi 后，通过 WebSocket 与电脑上的 Python 后端通信
- 物理按钮触发录音开始/结束，音频数据通过 WebSocket 实时传输

=====================
接线参考（ESP32-S3 → 各模块）
=====================

INMP441 麦克风:
  VDD  → 3.3V
  GND  → GND
  SD   → GPIO 4  (I2S Data In)
  SCK  → GPIO 5  (I2S Clock)
  WS   → GPIO 6  (I2S Word Select)
  L/R  → GND     (左声道)

MAX98357A 功放:
  VIN  → 5V (或 3.3V)
  GND  → GND
  DIN  → GPIO 15 (I2S Data Out)
  BCLK → GPIO 16 (I2S Clock Out)
  LRC  → GPIO 17 (I2S Word Select Out)

按钮:
  一端 → GPIO 0 (或其他 GPIO)
  另一端 → GND
  (使用内部上拉电阻，按下时为低电平)

=====================
与本项目集成的通信协议设计
=====================

ESP32 ←→ Python 后端（WebSocket）:

1. ESP32 → 后端:
   - {"type": "voice_start"}           // 按钮按下，开始录音
   - {"type": "voice_data", "audio": "<base64 PCM>"}  // 实时音频流
   - {"type": "voice_end"}             // 按钮松开/再按，录音结束

2. 后端 → ESP32:
   - {"type": "tts_start"}             // 开始播放 TTS
   - {"type": "tts_data", "audio": "<base64 PCM>"}   // TTS 音频流
   - {"type": "tts_end"}               // TTS 播放结束
   - {"type": "text", "content": "..."}  // 文本消息（可选显示在 OLED）
